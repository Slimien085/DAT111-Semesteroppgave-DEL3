HVORDAN KJØRE PROGRAMMET

1. Åpne mappen i terminalen (eller PyCharm).
2. Installer bibliotekene (første gang):
       pip install -r requirements.txt
3. Start programmet:
       python Semester26.py

Når programmet starter skrives en tabell med MAE og R² for alle modellene i terminalen,
og så åpnes vinduet med kartet.

BRUKERVEILEDNING
- Øverst til venstre velger du by (Bergen / Stavanger).
- Under velger du boligtype (enebolig / rekke / leilighet) og standard (dårlig ... luksus).
- Klikk et sted i kartet. Der vises estimert pris per m² (kr/m²) for et hus på 100 m².
- Stolpediagrammet viser pris per m² for 50, 100, 150 og 200 m².
  Fargen viser standard: rød = dårlig, gul = god, lysegrønn = meget god, grønn = luksus.
  Den stiplede linjen viser prisen per m² for 100 m².
- Aksene på kartet viser breddegrad (°N) og lengdegrad (°Ø).
- Nederst til venstre står posisjonen du klikket på, hvilken modell som er brukt, og MAE og R².
